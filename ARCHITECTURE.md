# FoundryKin — архитектура 0.8.33

## Источник состояния

Код: `arseninp/FoundryKin-Beta`, ветка `main`; точка проверки `aa0f357d5d26b131dc3bc5901c016fc0c6b67bcb`. Приложение открывается через `app.html`. Версия 0.8.33 задаётся FK_V; номера отдельных ресурсов используются для кэша и диагностики.

## Загрузка

CSS `fk-style.css` и Montserrat 400/500/800. JS: `fk-editor.js` → `fk-grid.js` → `fk-bg.js` → `fk-help.js` → `fk-tools.js` → `fk-shell.js` → `fk-ui.js` → `fk-app.js` → JSZip 3.10.1. Старый редактор дополнительно загружает three.js r128/JSZip.

`fk-editor.js` получает index.html через fetch, применяет общий массив PATCHES и вставляет результат в iframe.srcdoc с base href. NEWPATCHES из fk-grid, изменения fk-bg, fk-help и fk-tools добавляются в тот же массив. Это текущее устройство, не целевая архитектура. Перевод одного index.html без сверки патчей сломает якоря.

## Ответственность файлов

| Файл | Текущая роль |
|---|---|
| app.html | Разметка экранов, подключение ресурсов и FK_V. |
| fk-style.css | Базовые стили оболочки; часть переопределений в JS. |
| fk-app.js | Навигация, паки и форма, localStorage, импорт/экспорт, Add, диагностика. |
| fk-editor.js | PATCHES, iframe, tidy, FKE, режимы, контроль изменений. |
| fk-grid.js | Патчи каталога/моделей, ленивые карточки Find и их 3D-снимки, PNG/TGA, связь активного пака с редактором. |
| fk-bg.js | Патчи фона, тема iframe, прежний sticky-поиск, отключение старого переключения вида. |
| fk-help.js | Текстовые патчи, меню справки, информация файла/каталога, ручная загрузка и перехват Back для закрытия меню. |
| fk-tools.js | Внедрение рисования/палитры/инструментов, FKM, 16/32/64, SVG; извлечение тела функции inj для патчей. |
| fk-shell.js | SVG-лупа Find и преобразование заголовка редактора в название с пузырём файла через MutationObserver. |
| fk-ui.js | Цвета/нажатия/пузыри шапок, sticky Find с Back, корректировка шапки пака, синхронизация положения при прокрутке. |
| index.html | Старая база редактора, изменяемая на лету; не полная версия 0.8.33 сама по себе. |

fk-shell не является языковым модулем: он распознаёт текущий заголовок и переоформляет его. fk-ui делает внешнее оформление и плавающие шапки. Их роли пересекаются; при рефакторинге объединить оформление в исходном рендере шапки, не потерять вложенный пузырь файла.

## API и жизненный цикл

- FKE — граница оболочки и iframe: open, setMode/getMode, editTexture, files, current, dirtyNow/markSaved, busy, info, reset. fk-grid добавляет objInfo и обёртки.
- FKAPI внутри редактора — текущий блок, загрузка, счётчик правок, сбор файлов; grid() даёт каталог, файлы, dirty, select, load, discard, setPack, obj, shapeFor.
- FKAPP.migrate группирует импортированные текстуры в объекты; FKG даёт версию/состояние карточек.
- FKM внутри редактора — открытое меню и история браузера. Меню добавляет запись history, Back закрывает его первым; повторное нажатие/фон удаляют запись. Проверять совместную историю оболочки и iframe.
- При входе в Find из localStorage подставляются текстуры активного пака. При выходе из edit в search недобавленные правки восстанавливаются из пака. Add собирает изменённые файлы и сохраняет их в активный пак.

## Данные и рендер

Паки/настройки: fk070_packs/fk070_settings. История цвета/кисть: fk_hist, fk_hist_v2, fk_brush. Каталоги: foundrykin.catalog.v3, foundrykin.exist.v2. Внешние источники — Mojang bedrock-samples (blocks, terrain_texture, изображения), CDN и список файлов GitHub/jsDelivr.

Карточка .fkc состоит из .fkp (PNG-превью) и .fkn (двухстрочное название); fk-edited выделяет обе части рамкой. Камера ортографическая, углы (0.6155, -0.7854); центрирование по габаритам и только уменьшение. Живая модель находится в #stage, рисование — #ed. При отсутствии WebGL карточки без изображения. Каркас снят подменой THREE.LineSegments; создание геометрии рёбер в исходниках ещё осталось и требует удаления.

## Технический долг

1. Текстовые патчи и зависимость порядка их применения.
2. Проверки ошибок/каталога по русскому тексту; tidy ищет элементы по надписям. Язык пока смешанный, i18n.js в main нет.
3. Обёртки FKE и DOM-наблюдатели вместо явных вызовов, CSS распределён по файлам и инъекциям.
4. Скрытые узлы имени/экспорта и отключённые ветки старой базы, включая save/load и setFb/drawFb. Удалять исходный код, а не только скрывать его.
5. localStorage и ограничение импортируемых паков, отсутствие офлайна; повторная загрузка 64px требует проверки.

## Целевая структура — ещё не реализована

- app: экраны, навигация, исходный рендер общей шапки и формы.
- editor: холст, инструменты, история, палитра, события и текущая текстура.
- catalog: данные Mojang, модели/слоты и поиск.
- render: модель, текстуры, камера, статичные превью.
- storage: единый слой данных, позже IndexedDB.
- pack-io: manifest, импорт/экспорт и ошибки с кодами.
- help: справка и меню с единым жизненным циклом.
- i18n.js: единственный источник UI-строк; английская база, затем словари языков. Блоки/файлы — данные, не переводы.

Названия разделов выше — границы ответственности, не требование создать новый файл под каждую функцию. Существующие реализации заменять напрямую с удалением прежних, без новых слоёв исправлений. До записи полного набора проверять все функции 0.8.33 и их сохранность.
