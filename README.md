# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: Find, 3D-просмотр, рисование PNG, импорт/экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Статус на 2026-10-31

Проверенный HEAD перед обновлением документации: 5c5f9f4f449ba0aba3be6847cd09287f0d716130. Документальная запись не является выпуском приложения. Рефакторинг и модельный этап не завершены; по прежней проверке основной UI остаётся на legacy fk-модулях 0.9.1. HTML этой передачей не перечитан.

Важно: последний пакет хоруса записан некорректно. В catalog/rules/utility-parts.mjs попали заголовки и код предназначенного для другого файла dependencies.mjs; модуль синтаксически повреждён. Настоящий dependencies не получил chorus stem, часть согласованных тестов не вошла в коммит. Первый следующий кодовый шаг — восстановление целого пакета и проверка сохранённых файлов, а не продолжение переноса поверх ошибки. Эта документация код не исправляет.

Новый путь разделяет данные, resource ownership, aliases/forms/states, исходные ID и построение моделей. Выбор редактируемой PNG не управляет геометрией или стадиями; индексы вариантов и повторы сохраняются. Помимо прежних растений/устройств/гелей/пашни/снега, за OLDCHAT13 записаны корни, общий выбор состояний cube, полые composter/scaffolding, задние грани поршней, индексированные грибные варианты и общий cage для спавнеров/vault. Геометрия хоруса записана, но её пакет остаётся повреждённым и незавершённым.

Целевые тесты в прошлых чатах не равны полному validate/tests/compile/CI или визуальной приёмке PNG/WebGL/Android/export. В этой документальной передаче тесты не запускались. Актуальное число незакрытых исходных записей не установлено; старые счётчики не являются процентом готовности. Новый catalog/models не принят в основном редакторе; entities требуют общего source adapter и отложены. Unknown не заменяется кубом.
