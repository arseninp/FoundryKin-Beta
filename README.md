# FoundryKin

Редактор текстур для Minecraft Bedrock: паки, текстуры блоков из игры, 3D-превью, экспорт в `.mcpack`.

## Файлы

- `app-v0.7.html` — само приложение (v0.7.1): Create → паки → + Add texture, настройки.
- `index.html` — редактор текстур (v0.6.4). Приложение загружает его при открытии Add texture и применяет поверх него правки. Файл не переименовывать и не удалять.
- `ROADMAP.md` — планы развития.

## Запуск

Открывай приложение по адресу GitHub Pages: https://arseninp.github.io/FoundryKin-Beta/app-v0.7.html

Из скачанного файла на телефоне приложение не работает: редактор должен открываться с того же сайта, что и приложение. Первый запуск требует интернета (каталог блоков и библиотеки).

## Ветки

- `main` — рабочая ветка. Все новые версии заливаются сюда, GitHub Pages публикует её.
- `backup` — резервная копия последней стабильной версии. Обновляется раз в 3–4 обновления.
