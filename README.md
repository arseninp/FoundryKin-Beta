# FoundryKin

FoundryKin — мобильное веб-приложение для редактирования текстур блоков Minecraft Bedrock и сборки паков `.mcpack`. Текущая версия приложения — 0.8.23.

## Запуск

Адрес приложения: https://arseninp.github.io/FoundryKin-Beta/app.html. Это единственный поддерживаемый способ запуска. Для первого запуска нужен интернет: каталог блоков и библиотеки загружаются извне.

## Файлы

- `app.html` — оболочка приложения и подключение скриптов.
- `fk-app.js` — экраны, паки, хранение, импорт и экспорт `.mcpack`, диагностика.
- `fk-style.css` — стили оболочки и темы.
- `fk-editor.js` — загрузка редактора в iframe, патчи и связь редактора с приложением.
- `fk-grid.js` — сетка блоков, 3D-снимки карточек и дополнительные патчи редактора.
- `fk-bg.js` — фон, поиск, синхронизация темы и патчи удаления 2D-вида.
- `fk-help.js` — сокращённые подписи редактора и справка по кнопке `⋮`.
- `index.html` — старый редактор. При загрузке приложение применяет к его тексту патчи из JS-файлов; напрямую файл пока не правим. В дальнейшем его заменит модульный редактор.
- `TODO.md` — ближайшие задачи; `ROADMAP.md` — план развития.
- `ARCHITECTURE.md` — устройство проекта; `CONTEXT.md` — рабочий контекст.

## Данные и ограничения

Паки и настройки хранятся в `localStorage` браузера на устройстве. Очистка данных браузера удалит локальные паки, поэтому сохраняй экспортированные `.mcpack` и резервные копии данных. Импорт больших паков пока ограничен объёмом хранилища; ориентир — 2–3 МБ.

3D-превью требует WebGL и загрузки `three.js`. Если 3D недоступен, превью карточек остаётся пустым.
