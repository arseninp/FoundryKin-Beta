# FoundryKin

Мобильный редактор текстур Minecraft Bedrock и сборщик .mcpack. Версия 0.8.60. Документация от 2026-10-24; проверенный код main ad35c30b35f9d7ec7b6785471850bdc58508c771.

## Запуск

[Открыть приложение](https://arseninp.github.io/FoundryKin-Beta/app.html). app.html — оболочка, index.html — редактор в одном iframe. Нужны сеть/CDN и WebGL для 3D; PWA/гарантированного офлайна нет. Задержку обновления проверять по версии и публикации Pages; можно app.html?x=2, но не очищать данные сайта с паками.

## Работа

Create → создать/импортировать пак → Save → открыть пак → Find → блок → рисование → Add → экспорт .mcpack. PNG экспортируется отдельно. Рисование само не сохраняет в пак; выход с недобавленными правками требует подтверждения. Имя по умолчанию my_pack; поддерживаются латиница, цифры, пробелы, _ и -.

Кисть/ластик, заливка, пипетка, RGBA-замена, undo/redo, трансформации, HSV/RGBA/Hex и история цветов; темы и EN/RU/Auto, справка ⋮. Теперь кнопки показывают имена файлов без выдуманных назначений и дублирующего пузыря. Внешний вид 0.8.60 ещё ожидает отдельного подтверждения.

## Данные и ограничения

Паки хранятся в localStorage браузера; очистка удаляет их. Сохраняйте экспорт. Квота ограничивает импорт несколькими МБ. Общая поддержка больших/неквадратных текстур ещё не готова; адаптер Conduit требует проверки. Сохранение, гонки, память и навигация имеют открытые задачи. Права на ванильные ресурсы перед публичным/платным выпуском проверить отдельно.
