# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: поиск объектов, 3D/спрайт-просмотр, рисование, импорт/экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Статус на 2026-11-10

Проверенная кодовая точка перед обновлением документов:337f7537ccdad52ff828d70bcb7f20fcd4347f55. Основной editor compiled; рефакторинг/физическая чистка legacy/полная визуальная приёмка не завершены.

Сохранены material families/double slabs/signs/cave vines/hanging mounting/observer, reuse frames/history/GPU textures и PNG encoding по изменению. Предметный atlas уже содержит75 записей/items-000.json, объявленные иконки открываются плоско внутри существующих объектов.

В OLDCHAT31 MERS подключена к polished cinnabar как дополнительный editable resource без PBR, добавлена диагностика исходного TGA. Исправлен UV-масштаб inactive conduit. Владелец сообщил, что conduit/MERS работают; побайтовая сохранность каналов и полный export не объявляются доказанными.

Стоячее/настенное знамя объединены, fallback-доски исключены из его рабочих ресурсов. Ресурсы размещены в сворачиваемых разделах Основа/Рисунки/Дополнительные исходники; готовый illager в Основе, название слева/счётчик и стрелка справа. Ошибка размеров snapshot после макета исправлена отдельно. Bubble337f753 уже сохраняет18 настоящих ресурсов эффекта без pumpkin_side; его UI-группировка ещё впереди.

## Что осталось

Следующая работа — удобные группы ресурсов пузырей и рассмотрение других длинных списков через тот же механизм. Начальный разворот подтверждённых групп моделей, швы/пропадающие поверхности, анимационный проигрыватель, плашки и сквозная приёмка остаются открытыми.

Item-обозначение — будущий пункт макета: отличать предметный спрайт от model texture, flat/no rotation, ресурс той же карточки. Примерка рисунков/слои/миниатюры знамён ещё не завершены; новая палитра/цветные PNG не запрошены.

Bubble/end используют общий sprite preview исходной текстуры, не симуляцию Minecraft; no-preview режим не выбран. Масштаб маленьких объектов пока не меняется. Следующая согласованная runtime-версия1.0.0, данный docs-only пакет её не устанавливает и не является выпуском.
