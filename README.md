# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: общий каталог, 3D/спрайты, рисование и .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

Кодовая база передачи 2026-11-14: 90957614641e0f832991656f182da061bbe04e01/main. app.html/index.html — 0.9.17; preview.html — 0.9.9. Свежий полный CI и точный опубликованный Pages SHA не подтверждены.

Реализованы сравнение до/после с playback обеих версий, рамка блокировки PNG, акцентные карточки, внутренний бэкап на пак в общем списке и явный выбор цвета кисти. Последняя правка рисования принята владельцем. Это не полная приёмка всех функций.

Старое улучшение сохранения снято; швы и технический аудит открыты. История в Git сохранена. Пакет меняет только документы, не runtime или данные владельца.
