# FoundryKin

Мобильный веб-редактор текстур Minecraft Bedrock: поиск блока, 3D-просмотр, рисование PNG, сборка .mcpack. Статус: бета 0.8.65. Цель: стабилизировать и выпустить коммерчески.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Порядок чтения для ассистента

1. CONTEXT.md — состояние, решения владельца, правила работы. Читать первым.
2. ARCHITECTURE.md — карта кода с указателями файл::символ, известные дефекты.
3. TODO.md — очередь работ и критерии готовности.
4. ROADMAP.md — этапы до релиза.

Документы переписаны 2026-10-25 под код 0.8.65 (эталон: ветка backup-0.8.65-2026-10-25, коммит 9d12674). Вопросы владельцу до чтения не нужны: ответы в CONTEXT.md.

## Сценарий пользователя

Create → создать или импортировать пак → Save → открыть пак → Find → блок → рисование → Add → экспорт .mcpack. PNG экспортируется отдельно. Рисование само не сохраняет: нужен Add; выход с несохранёнными правками требует подтверждения.

Инструменты: кисть и ластик 1–8, заливка, пипетка, RGBA-замена, undo/redo, повороты и отражения, HSV/RGBA/Hex, история 20 цветов, EN/RU/Auto, темы.

## Ограничения

- Нужны сеть и CDN (Three.js r128, JSZip 3.10.1, каталог Mojang bedrock-samples) и WebGL. Офлайна и PWA нет.
- Паки лежат в localStorage браузера: очистка данных сайта их удаляет. GitHub хранит только код. Экспортируйте паки.
- Холст квадратный 16/32/64; неквадратные атласы поддержаны частично (см. ARCHITECTURE.md).
- Права на ресурсы Mojang нужно проверить до публичного или платного релиза.
