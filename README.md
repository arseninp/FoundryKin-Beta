# FoundryKin

Мобильный веб-редактор текстур Minecraft Bedrock: Find, формы блоков, 3D-просмотр, рисование PNG, импорт/экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Сохранность

Рисование сохраняется в пак через Add. Паки находятся в localStorage (`fk070_packs`); GitHub backup сохраняет код, не паки. Не очищать данные сайта ради кэша. Оригинальные пути ресурсов сохранять.
