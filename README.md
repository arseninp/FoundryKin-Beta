# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: Find, 3D-просмотр, рисование PNG, импорт/экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Статус на 2026-10-30

Проверенный HEAD перед документальной передачей: 2a109dc3c527d2cd7ad0d6221212ce47af15c0f9 — перенос hopper, grindstone и item frames. Документы обновлены после OLDCHAT11; это не новый выпуск приложения.

По истории рабочие страницы используют legacy fk-модули 0.9.1, а новый каталог, модели и переключатели пока не подключены к UI. library.mjs непосредственно проверен: подключены фабрики вплоть до workshop, включая potted azalea.
