# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: единый каталог, 3D/спрайты, рисование и .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

Статус 2026-11-13: кодовая база перед обновлением документов — 84f33e5a73426a5567bcc359dac1e4b73e701a0d/main. Оболочка app.html и редактор index.html — 0.9.13; отдельная preview.html — 0.9.9. Этот пакет меняет только документы. Полный свежий CI и точный SHA публикации инструментально не подтверждены.

Уже реализованы общий каталог/модели, Play/Pause и ленивые миниатюры, общая политика глубины восьми классов вместо исключения пиглина, очистка рабочих ресурсов голов, перемещение/масштабирование PNG-поля и очистка сохранённых цветов. Последний перевод палитры на canvas принят владельцем: 2026-11-13 подтверждены нормальные цвета в Samsung Internet без подмены RGBA/HEX/пипетки. Дубль подписи версии удалён.

Открыты швы и незавершённый аудит геометрических поправок, сравнение до/после от входа в карточку, улучшение сохранения и единая система оформления. 3D-рисование пока только обсуждалось. Фон #30312b не применён.
