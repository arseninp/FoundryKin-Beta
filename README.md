# FoundryKin

Мобильный веб-редактор текстур Minecraft Bedrock и сборщик .mcpack. Версия кода в main — 0.8.40 (1053bdb). Новейшая сборка ещё ожидает телефонной проверки.

## Запуск

https://arseninp.github.io/FoundryKin-Beta/app.html

app.html — оболочка приложения. index.html — внутренний документ редактора, открываемый в iframe. Интернет нужен для каталога/ресурсов Mojang, three.js, JSZip и Montserrat; гарантированного офлайна и PWA пока нет.

## Работа

1. Create → создать пак или импортировать Mcpack.
2. Заполнить форму и нажать Save. Без имени используется my_pack; имя ограничено латиницей, цифрами, пробелами, _ и -.
3. Открыть пак → Find → выбрать блок → изменить текстуру → Add в шапке.
4. Экспортировать .mcpack из списка паков. Download в редакторе сохраняет PNG.

Рисование не добавляет текстуру в пак автоматически. При выходе с недобавленными правками есть подтверждение. Имя/автор/описание/версии/иконка формы — черновик до Save; обработку ошибок сохранения и позднего чтения файлов ещё нужно доработать.

Редактор содержит кисть/ластик 1–8, заливку, пипетку, замену точного цвета, undo/redo, повороты/отражения, альфу и палитру HSV/RGBA/Hex с историей. Формы выбираются SVG-кнопками. Слоты текстур — текст по именам файлов; объединённые top + bottom сохраняются. Справка — ⋮. Настройки языка — Auto/English/Русский, темы — светлая/тёмная/системная.

## Устройство

Редактор загружается обычными модулями, без PATCHES и подмен HTML. Общий fk-base.css используется оболочкой и iframe для шрифта, палитр и шапок. Новые экраны должны использовать его компоненты.

- app.html, fk-app.js, fk-style.css — экраны оболочки, паки, форма, pack-io и диагностика.
- fk-editor.js — мост FKE к iframe.
- index.html, fk-core.js — разметка редактора, модель/холст/история/состояние.
- fk-catalog.js — данные Mojang, формы/слоты, загрузка PNG/TGA.
- fk-tools.js — рисование, палитра, настройки, меню.
- fk-grid.js — поиск, карточки и 3D-снимки.
- fk-help.js — справка, каталог/ошибки.
- fk-i18n.js — общий словарь EN/RU.
- fk-base.css — общая база оформления.

Для продолжения разработки читать CONTEXT.md, ARCHITECTURE.md, TODO.md и ROADMAP.md. Лимит файла — 25 000 Б UTF-8.

## Данные и ограничения

Паки находятся в localStorage данного браузера на телефоне. Очистка данных браузера удаляет их. Сохранять экспорт паков и при необходимости выгрузку данных из настроек; backup в GitHub хранит код, не паки пользователя.

Импорт ориентировочно 2–3 МБ и зависит от квоты. 3D требует WebGL. Часть моделей приблизительная. Полный цикл 64px, отказы хранилища, асинхронные переходы и зависания ещё проверяются. Сброс к ванильной текстуре пока не реализован. Права на использование ресурсов в публичном/платном приложении требуют решения.
