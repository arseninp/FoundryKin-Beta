# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: каталог, общий 3D/спрайт-просмотр, рисование и экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

Состояние документации на2026-11-15: кодовый HEAD4ad5e7b9de9a581bb22080195959a9b0abb6c558/main. Документ редактора index.html0.9.24, оболочка/FK_V0.9.20, preview.html0.9.9. Подписи версий пока разрознены; единый источник запланирован на рефакторинг. Точный опубликованный Pages SHA и свежий полный CI этой передачей не подтверждены.

Реализованы До/после с playback, PNG pan/zoom, явный выбор кисти, внутренний бэкап на пак, разделы настроек и тематический выбор темы/языка. Личные палитры управляются в Персонализации и выбираются/сохраняются в редакторе; Mix/Микс — история рабочих цветов. В меню формы есть количество 1,3 (3×1),9 (3×3), с общими ресурсами и без второго редактора.

Внешний вид палитры0.9.22 принят владельцем; это не полная приёмка хранения, бэкапов или нового повторного просмотра. Обучение отложено до аккаунтов и достаточной клиентской базы; облака/синхронизации сейчас нет.
