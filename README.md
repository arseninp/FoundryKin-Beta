# FoundryKin

Мобильный веб-редактор текстур Minecraft Bedrock: каталог блоков и форм, общий просмотр Find/редактора, рисование PNG, импорт и экспорт `.mcpack`.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Состояние на 2026-10-28

Документация сверена с кодовой точкой `caaff4609af0a5b51a52e5caeca976c7674da31a` и последними сообщениями владельца. Блоки проходят ручную проверку по английскому алфавиту; расширенный каталог предметов и универсальная загрузка сущностей ещё впереди. Нельзя считать весь каталог полностью проверенным.

Версии сейчас неоднородны: оболочка `FK_V` и большинство ссылок ресурсов — `0.8.92`, новый `fk-blocks-b.js` подключён с `?v=0.8.93`. Сообщения коммитов 0.8.93 не означают, что версия оболочки поднята. Этот документальный пакет не меняет код, версии, кэш, паки или ветки.

## Работа с паком

Create → создать/импортировать пак → Save → открыть пак → Find → выбрать блок/форму → рисовать → Add → экспортировать `.mcpack`. Отдельный PNG тоже экспортируется. Рисование само по себе не сохраняет правки в пак: нужен Add. Предусмотрено подтверждение выхода с несохранёнными изменениями.

Инструменты: кисть и ластик 1–8, заливка, пипетка, RGBA-замена, undo/redo, поворот и отражение, HSV/RGBA/Hex, история цветов; EN/RU/Auto и темы.

## Просмотр и данные

Find снимает ту же модель с той же подготовкой текстур и базовой камерой, что использует редактор. Отдельного рендера геометрии карточек нет. Один WebGLRenderer, ручной поворот, без idle-вращения.

Источник данных и PNG/TGA закреплён: `Mojang/bedrock-samples@46ba6ea985fb5a92d79a9419198f10dda14c199d`. `data/catalog-candidate/` — рабочие данные, историческое имя не означает отключённый кандидат. Семейства готовятся в `data/catalog-families/`, специальные объединения дополняются в runtime.

Добавлены составные растения, состояния лампы/факела, рамка портала Края, стадии культур, поршни и другие специальные модели. `end_portal` остаётся фронтальным спрайтом; `end_portal_frame` — отдельная модель. Последняя точечная правка: одна карточка `pumpkin`, форма для обычного `trapdoor`, удаление старой геометрии sunflower. Статусы проверки см. в TODO.

## Проверки

```sh
for file in fk-*.js; do node --check "$file"; done
node --test tools/*.test.mjs
```

`validate.yml` выполняет синтаксис и тесты с правами только на чтение, без автокоммитов. Текущий успешный CI-прогон этой документацией не утверждается. Тесты на заглушках не заменяют WebGL на телефоне, аудит UV и цикл Add → reopen → PNG → `.mcpack`.

## Ограничения и сохранность

- Нужны сеть, WebGL, Three.js r128 и JSZip 3.10.1; это не офлайн/PWA.
- Паки находятся в `localStorage`. GitHub-бэкап сохраняет код, не паки; очистка данных сайта удаляет пользовательские данные.
- Холст 16/32/64; произвольные большие, смешанные и неквадратные атласы поддержаны не полностью.
- Полная поддержка entity-геометрии, голов, табличек и всех предметов не завершена.
- Перед распространением/коммерческим выпуском проверить права на ресурсы Mojang.
