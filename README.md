# FoundryKin

Мобильный веб-редактор текстур Minecraft Bedrock и сборщик .mcpack. Версия кода в main — 0.8.44 (28258ae). Сборки 0.8.42–0.8.44 ещё ожидают проверки на телефоне.

## Запуск

https://arseninp.github.io/FoundryKin-Beta/app.html

app.html — оболочка приложения. index.html — внутренний документ редактора, открываемый в iframe. Интернет нужен для каталога и ресурсов Mojang, three.js, JSZip и Montserrat; гарантированного офлайна и PWA пока нет. Если после обновления на телефоне старая версия, откройте адрес с параметром, например app.html?x=2.

## Работа

1. Create → создать пак или импортировать Mcpack.
2. Заполнить форму и нажать Save. Без имени используется my_pack; имя — латиница, цифры, пробелы, _ и -.
3. Открыть пак → Find → выбрать блок → изменить текстуру → Add в шапке.
4. Экспортировать .mcpack из списка паков. Download в редакторе сохраняет PNG.

Рисование не добавляет текстуру в пак автоматически. При выходе с недобавленными правками есть подтверждение. Имя, автор, описание, версии и иконка формы — черновик до Save; обработку ошибок сохранения и позднего чтения файлов ещё нужно доработать.

Редактор: кисть/ластик 1–8, заливка, пипетка, замена точного цвета, undo/redo, повороты/отражения, альфа, палитра HSV/RGBA/Hex с историей. Формы выбираются SVG-кнопками, слоты текстур — текстом по именам файлов. Растения, кристаллы, бамбук, рельсы и лозы показываются своими моделями без выбора «куб». Связанные блоки объединены: лианы cave_vines (body/head) и аметисты (кластер и три стадии) — одна карточка со слотами. Справка — ⋮. Язык — Auto/English/Русский, тема — светлая/тёмная/системная.

## Устройство

Редактор загружается обычными модулями, без PATCHES и подмен HTML. Общий fk-base.css даёт шрифт, палитры и шапки оболочке и iframe. Модели блоков строит только fk-shapes.js, им пользуются и редактор, и карточки Find.

- app.html, fk-app.js, fk-style.css — экраны оболочки, паки, форма, pack-io, диагностика.
- fk-editor.js — мост FKE к iframe.
- index.html, fk-core.js — разметка редактора, холст, история, состояние.
- fk-catalog.js — данные Mojang, формы, особые блоки и группы, загрузка PNG/TGA.
- fk-shapes.js — построители 3D-моделей.
- fk-tools.js — рисование, палитра, настройки, меню.
- fk-grid.js — поиск, карточки и 3D-снимки.
- fk-help.js — справка, каталог и ошибки.
- fk-i18n.js — словарь EN/RU.
- fk-base.css — общая база оформления.

Для продолжения разработки читать CONTEXT.md, ARCHITECTURE.md, TODO.md и ROADMAP.md. Лимит файла — 25 000 Б UTF-8.

## Данные и ограничения

Паки находятся в localStorage браузера на телефоне; очистка данных браузера удаляет их. Сохраняйте экспорт паков; backup в GitHub хранит код, не паки пользователя.

Импорт ориентировочно 2–3 МБ и зависит от квоты. 3D требует WebGL. Часть моделей приблизительная; классификация растений и плоских блоков идёт по именам, блоки вне списков остаются кубами. Полный цикл 64px, отказы хранилища, асинхронные переходы и зависания ещё проверяются. Сброс к ванильной текстуре пока не реализован. Права на использование ресурсов Mojang в публичном и платном приложении требуют решения.
