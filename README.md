# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: Find, 3D-просмотр, рисование PNG, импорт/экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Статус на 2026-10-31

Проверенная кодовая точка перед обновлением документов: 4c52b9d5508422e705b4e5ef28056391350d2ecd — назначения пашни и снежного слоя, ресурсные роли пашни и интеграционные тесты. Обновление документов не является выпуском приложения.

Рефакторинг не завершён. По истории рабочий UI использует legacy fk-модули 0.9.1; новая цепочка catalog/models пока не подключена к основному редактору. HTML этой документальной передачей повторно не проверен. library.mjs непосредственно проверен: подключены новые фабрики, включая gels, specials, dripleaf, sculk, dried-ghast и barrel. Назначения slime/honey_block/farmland/snow_layer уже записаны; имя мёда в каталоге и построителе совпадает.

Новый путь разделяет данные, ресурсные роли, aliases/forms/states, доступ к исходным ID и построение моделей. Сохраняются повторяющиеся индексы вариантов; выбор редактируемого PNG не должен управлять геометрией или стадиями. За последние проходы перенесены многочисленные специальные модели, растения, устройства и их явные состояния; добавлены двухобъёмные slime/honey и низкие farmland/snow. Настенные коралловые веера не возвращаются отдельными карточками; для них и candle_cake записаны правила aliases.

Существующий аудит расширен проверкой нормализации/ресурсов/зависимостей. Актуальный полный отчёт, весь validate/tests/compile, зелёный CI, реальный WebGL/Android и экспортная приёмка не подтверждены. Исторические счётчики назначений не являются процентом готовности. Общего entity source adapter пока нет; entities и связанные объекты отложены. Unknown не подменяется кубом.
