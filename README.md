# FoundryKin

Мобильный веб-редактор текстур блоков Minecraft Bedrock и сборщик `.mcpack`. Рабочая версия — 0.8.33.

## Запуск

https://arseninp.github.io/FoundryKin-Beta/app.html — единственный поддерживаемый способ запуска. `index.html` является внутренней базой редактора; открывать приложение нужно через оболочку. Для первого запуска необходим интернет: данные Mojang, JSZip, three.js и Montserrat загружаются извне. PWA и гарантированный офлайн пока не реализованы.

## Работа

1. Create → «Создать пак» либо «Добавить Mcpack».
2. Новая форма сохраняет пак только по «Сохранить». Пустое имя становится my_pack. Имя — латиницей. «Изменить» открывает ту же форму; выход без Save отменяет правки, включая иконку.
3. Открыть пак → Find → выбрать блок → редактировать текстуру → «Добавить» в шапке.
4. Экспортировать mcpack из списка паков. «Скачать» в редакторе выгружает PNG.

Редактор: вращаемая модель, кисть/ластик 1–8, заливка, пипетка, замена точного цвета (капля), отмена/повтор, повороты и отражения. Палитра HSV/RGBA/Hex и история до 20 цветов, удаление удержанием. Настройки — разрешение 16/32/64. Справка — ⋮. Присутствуют светлая и тёмная темы, SVG и плавающие пузыри шапок.

## Файлы

- app.html — оболочка, экраны, ресурсы и версия приложения.
- fk-app.js — навигация, паки/форма, хранилище, импорт/экспорт, Add, диагностика.
- fk-style.css — базовые стили оболочки.
- fk-editor.js — iframe, PATCHES, FKE и интеграция старого редактора.
- fk-grid.js — каталог/модели и патчи, карточки Find и статичные 3D-превью, PNG/TGA, активный пак.
- fk-bg.js — базовые патчи фона и синхронизация темы редактора.
- fk-help.js — справка, каталог/ошибки и меню ⋮.
- fk-tools.js — инструменты, палитра, настройки и менеджер меню FKM, внедряемые патчами.
- fk-shell.js — бесцветная лупа Find и оформление однострочного заголовка редактора с пузырём файла.
- fk-ui.js — текущие цвета, отклик на нажатие, плавающие шапки и отступы при прокрутке.
- index.html — старый исходник редактора, который приложение преобразует перед загрузкой; его содержимое отдельно не равно интерфейсу 0.8.33.
- CONTEXT.md — точка входа и правила работы; ARCHITECTURE.md — устройство и технический долг; TODO.md — открытые задачи; ROADMAP.md — стратегия.

## Данные и ограничения

Паки и настройки находятся в localStorage браузера на этом устройстве. Очистка данных браузера удалит паки: сохранять экспорт и резервные копии данных. Импорт ограничен примерно 2–3 МБ и фактической квотой хранилища; IndexedDB ещё нет.

3D требует WebGL; без него карточки могут остаться без изображения. Часть моделей приблизительная. Разрешение 64px добавлено, но его полный цикл повторного открытия/импорта/экспорта требует регрессионной проверки. Сброс грани к оригиналу пока отсутствует.

UI пока смешивает русский и английский. Единый словарь, полная английская база и RU/EN — следующая задача, не реализованная возможность. Блоки и имена файлов остаются английскими данными Mojang. Права на использование ванильных ресурсов в публичном/платном приложении требуют решения.
