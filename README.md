# FoundryKin

Мобильный веб-редактор текстур Minecraft Bedrock: каталог блоков и форм, общий просмотр Find/редактора, рисование PNG, импорт и экспорт `.mcpack`.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Работа с паком

Create → создать/импортировать пак → Save → открыть пак → Find → выбрать блок/форму → рисовать → Add → экспортировать `.mcpack`. Рисование само по себе не сохраняет правки в пак: нужен Add. Предусмотрено подтверждение выхода с несохранёнными изменениями.

Инструменты: кисть и ластик 1–8, заливка, пипетка, RGBA-замена, undo/redo, поворот и отражение, HSV/RGBA/Hex, история цветов; EN/RU/Auto и темы. Светлая «бумажная» тема принята; палитру тёмной темы владелец выберет позже.

## Просмотр и данные

Find снимает ту же модель с той же подготовкой текстур и базовой камерой, что использует редактор. Один WebGLRenderer, ручной поворот, без idle-вращения.

Источник данных закреплён: `Mojang/bedrock-samples@46ba6ea985fb5a92d79a9419198f10dda14c199d`. `data/catalog-candidate/` — рабочие данные; `data/catalog-families/` — готовые семейства; специальные объединения дополняются в runtime.

Состояния просмотра (репитер: питание и задержка 1–4; компаратор: питание и сравнение/вычитание) выбираются в тематическом окне и не меняют PNG и паки.

## Проверки

```sh
for file in fk-*.js; do node --check "$file"; done
node --test tools/*.test.mjs
```

`validate.yml` выполняет синтаксис и тесты с правами только на чтение, без автокоммитов. Успешный CI-прогон на 0.9.1 не подтверждён. Тесты на заглушках не заменяют WebGL на телефоне, аудит UV и цикл Add → reopen → PNG → `.mcpack`.

## Ограничения и сохранность

- Нужны сеть, WebGL, Three.js r128 и JSZip 3.10.1; это не офлайн/PWA.
- Паки находятся в `localStorage`. GitHub-бэкап сохраняет код, не паки; очистка данных сайта удаляет пользовательские данные.
- Холст 16/32/64; произвольные большие, смешанные и неквадратные атласы поддержаны не полностью.
- Полная поддержка entity-геометрии, голов, табличек и всех предметов не завершена.
- Перед распространением/коммерческим выпуском проверить права на ресурсы Mojang.
