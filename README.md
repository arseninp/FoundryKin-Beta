# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: поиск объектов, 3D/спрайт-просмотр, рисование, импорт/экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Статус на 2026-11-10

Проверенная кодовая точка перед обновлением документов: 8c3805b4f58c485308e2cd1bc6142a7565c0e186. Основной редактор уже использует compiled catalog; описание «editor остаётся legacy» устарело. Рефакторинг, физическая чистка старых файлов и полная визуальная приёмка не завершены.

Сохранены материальные семейства, обработка двойных плит через aliases/формы, объединение standing/wall sign и частей cave vines, выбор крепления hanging sign, observer off/on. Улучшены повторное использование кадров/истории и GPU-текстур, PNG-кодирование выполняется по изменению.

Предметные иконки не только поддерживаются кодом генерации: в сохранённом manifest уже есть items-000.json и 75 записей предметного атласа. Выбранная объявленная иконка получает плоский просмотр; обычный ресурс возвращает модель. Это ещё не доказательство полной проверки каждого сценария редактирования/экспорта.

## Что осталось

Ближайшая задача — polished_cinnabar_mers.tga как дополнительная редактируемая карта с безопасным сохранением каналов, без имитации PBR/мерцания. Далее conduit и другие сообщения о дефектах моделей, швах и первоначальном развороте. Проигрыватель анимаций и плашки общих текстур/ограничений просмотра ещё не реализованы.

Bubble/end используют общий спрайт-просмотр исходной текстуры, не симуляцию игрового эффекта; отдельный режим без renderer не выбран. Масштаб маленьких объектов пока не меняется. Следующая согласованная runtime-версия 1.0.0, но этот документальный пакет её не устанавливает и не является выпуском.

## Проверки

В OLDCHAT30 владелец сообщил об улучшении скорости с оставшейся задержкой около полсекунды, позднее — что в приложении всё нормально. Это не полная приёмка всех моделей и редактора. Локальные тесты отдельных пакетов из архива не свежий полный CI. В текущем документальном проходе приложение и тесты не запускались; результат всех последних Actions не установлен.

Остаются real PNG/TGA/WebGL/UV/alpha/Android и сквозные Find → форма/состояние/ресурс → рисование/история → Add/reopen/export. Числа исходных IDs, расширенных records и видимых карточек не равны числу принятых моделей.
