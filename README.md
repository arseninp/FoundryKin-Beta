# FoundryKin

Мобильный веб-редактор текстур Minecraft Bedrock: каталог и поиск блоков, общий 3D-просмотр, рисование PNG, сборка `.mcpack`.

Текущая версия main: 0.8.88 (бета). Владелец принял работу каталога, семейств и бледного ковра на телефоне 2026-10-27. Тесты Node и проверки на заглушках не заменяют полный WebGL/Android-аудит и экспортный прогон.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Документация

1. `CONTEXT.md` — решения владельца, состояние проекта и ближайшие задачи; читать первым.
2. `ARCHITECTURE.md` — актуальная карта кода и ограничения реализации.
3. `TODO.md` — очередь работ и отдельно перечисленные проверки.
4. `ROADMAP.md` — этапы развития.

GitHub-бэкап сохраняет код, но не паки пользователя в `localStorage`. Перед серьёзными изменениями сначала проверять актуальную постоянную ветку `backup`.

## Сценарий пользователя

Create → создать или импортировать пак → сохранить → открыть пак → Find → выбрать блок или форму семейства → рисовать → Add → экспортировать `.mcpack`. PNG также экспортируется отдельно. Рисование само не сохраняет изменения в пак: для этого нужен Add. Выход с несохранёнными правками запрашивает подтверждение.

Инструменты: кисть и ластик 1–8, заливка, пипетка, RGBA-замена, undo/redo, поворот и отражение, HSV/RGBA/Hex, история цветов, EN/RU/Auto и темы.

## Общий просмотр

Карточка Find — снимок того же общего пути модели и подготовки текстур/материалов, который используется редактором. Find и редактор используют `FKView` и один WebGL-рендерер; отдельная карточная геометрия не поддерживается.

Shelf реализован. Семейства шерсти и мха содержат ковры; формы сохраняют собственные ресурсы. Бледный ковёр имеет обе боковые текстуры и переключатели состояния только для просмотра. Сетка холста не попадает в экспорт. Следующий отдельный дефект — бамбуковые забор и калитка; причина ещё проверяется. См. TODO.md.

## Ограничения

- Нужны сеть, CDN (Three.js r128, JSZip 3.10.1), картинки Mojang и WebGL. Данные каталога поставляются вместе с приложением; ресурсы закреплены на одном коммите Mojang. Это ещё не офлайн/PWA.
- Паки лежат в `localStorage` браузера; очистка данных сайта их удалит. Экспортируйте паки отдельно.
- Холст квадратный 16/32/64. Большие, смешанные и неквадратные атласы поддерживаются не полностью.
- Перед публичным или платным выпуском нужно проверить права на распространяемые ресурсы Mojang.
- Полный список незавершённых проверок и технических ограничений находится в `TODO.md` и `ARCHITECTURE.md`.
