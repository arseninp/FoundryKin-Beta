# FoundryKin

Мобильный редактор текстур Minecraft Bedrock: Find, 3D-просмотр, рисование PNG, импорт/экспорт .mcpack.

Приложение: https://arseninp.github.io/FoundryKin-Beta/app.html

## Статус на 2026-11-03

Кодовый HEAD перед обновлением документов: d7fb21715a633ccd61a4caf7ca78373e1289aa2a. Рефакторинг и блоковый этап не завершены; это не выпуск. Основной UI по прежней проверке использует legacy 0.9.1, здесь HTML заново не проверялся.

В новом пути записаны каталог/модели, составные плод+стебель и budding amethyst, aquatic/propagule/kelp, emissive plants, материалы и canvas/GPU texture lifecycle.
