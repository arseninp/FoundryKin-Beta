## Не потерять окончательные решения

- Bubble/end сохраняют общий sprite renderer и квадратную сетку. Обсуждавшийся no-preview сценарий отклонён позднейшим решением; не реализовывать его по ранним репликам архива.
- Нужна пометка об ограничении: исходная текстура не воспроизводит игровой эффект Minecraft. Плашки пока не реализованы, содержание требует уточнения.
- Shared-плашка — для активного файла с конкретными связанными видимыми карточками, включая зависимости. Не список всех shared files объекта.
- Playback — play/pause/timing/order/model sync/export; ручной frame click не проигрыватель.
- Фильтр иконок отложен; направление — адресный вход на ресурс той же карточки.
- Масштаб пока не трогать. Ориентация — свойство показа, без зеркалирования; 180° не применять всем моделям вслепую.
- Следующая согласованная версия 1.0.0, но docs-only запись не меняет runtime и не означает выпуск.
