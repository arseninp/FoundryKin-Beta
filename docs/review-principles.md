## Окончательные решения важнее промежуточных

Раннее предложение удалить render для bubble/end отменено дальнейшим обсуждением: сохраняется общий sprite/WebGL и квадратные cards. No-preview/пустой builder/новый renderer не реализовывать. Будущая пометка честно объясняет отсутствие игрового эффекта; это не повод скрыть сломанную модель.

MERS — дополнительная карта внутри polished cinnabar, без PBR/мерцания. Её подключение пока не записано. Риск потери каналов на canvas-пути проверить, не объявлять доказанным повреждением и не лечить принудительной непрозрачностью.

Shared-плашка относится к активному файлу и конкретным связанным карточкам/формам/состояниям, включая borrowed dependencies, а не ко всем files объекта. Содержание плашек ещё уточняется. Playback — отдельная незавершённая функция. Масштаб пока не менять. 1.0.0 — решение для следующего согласованного runtime обновления, не автоматически состоявшийся релиз.

## Исправлять причину

Один каталог, runtime, picker/menu и ресурсный индекс. Не дублировать таблицы, не прятать ошибки фильтрами Find, не наращивать resolve исключениями. Общий дефект — в общем слое, неверные UV/геометрия — в builder, ориентация показа — в общем контракте карточки/editor. Поворот не зеркалирование и не замена проверки UV.

Aliases требуют полной редакторской эквивалентности, не общей PNG. Double slab отличия сохраняются family form, smooth stone side не терять. Строгую валидацию b82838b не ослаблять. Infested/waxed не разъединять ради нового круга объединений. Standing/wall и cave_vines уже связаны; готовые builders не писать повторно.

Сохранять source records/IDs/reopen, owned/carried/icons/indexed repeats/dependencies без ownership transfer, sheets без незапрошенных copies/crops, PNG/form/slot/state/pose независимо. Unknown не cube, неоднозначность не первый PNG. Окисления раздельны. Chest/shulker whole-block facing не возвращать; open/lid/double, ender без double. Player head/hat/full sheet/routes и прочие исторические модельные ограничения сохранять.

Semi whole-sheet/inflate/стыки/UV пока диагностические направления: не глобальные DoubleSide/opaque/alpha=255. Не считать Java-reference доказательством корректности всего resource→build→render пути. Материалы заимствуют GPU textures, texture layer владеет ими; async/history/storage rollback/cleanup/limits/cache/retry не ломать ради скорости.

## Подтверждения и непрерывная работа

Одна согласованная задача без искусственных остановок. Перед каждой внешней записью точное системное подтверждение файлов и полного содержимого; общая просьба продолжать не безусловное разрешение. После одобрения ровно согласованный write, затем saved diff/content и дальнейшая подготовка до следующего подтверждения/решения/реального блокера. После неоднозначного сбоя сначала проверить GitHub, не дублировать запись вслепую.

Писать кратко и понятно по-русски, не перекладывать проектирование/отладку на владельца, не обещать фон. Подтверждение объяснять обычным текстом: отдельная форма может не отображаться. Не обещать Node/WebGL/Actions без доступного инструмента.

Только main; <25000 UTF-8 bytes/file, validators не ослаблять. Новые permanent tests отдельно согласовывать, существующие не удалять массово. В main разрешено менять/удалять нужное после проверки зависимостей, но не бэкап. Физическая legacy cleanup ещё не завершена; FKCatalog.loadAny нужен PNG/TGA.
