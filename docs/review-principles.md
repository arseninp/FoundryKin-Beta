# Review principles

The owner reviews the catalog by scrolling through every model and noting problem points.

- A problem found on one item usually applies to every analogous item. Fix the whole class at once: all coral kinds and their dead variants, all wood types, all colours, all copper stages.
- Do not wait for the owner to report each sibling separately. If a fix cannot safely cover the whole class, say which members were left out and why.
- Leftover forms (slabs, stairs, walls, buttons, plates, wall fans) that repeat a base block must not appear as separate catalog cards. Bamboo fence and gate are accepted separate models.
- Write directly to the application source; do not route edits through one-off Actions workflows.
