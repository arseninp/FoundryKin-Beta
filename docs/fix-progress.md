## Контракты D06/U03

fk-pack-data.mjs проверяет root/packs/active, поля паков, textures/obj/all, внешний контейнер backupEntries со строковыми записями. Прежние defaults/fresh нормализуются только в памяти; неизвестные поля сохраняются. Это не PNG decode/CRC, проверка архивов, внутреннего JSON снимков или дублей ID/путей.

До проверки данных body inert. Регистрация обработчиков настроек остаётся синхронной перед fk-settings-picker.js. Ошибка чтения/JSON/структуры помечает ключ unreadable и не меняет исходную запись. writable защищает save и commitData, включая host бэкапов. Выгрузка пустого состояния вместо непрочитанных данных блокируется. Отсутствующая запись допускает первое сохранение; quota корректных данных допускает повтор. Неверные настройки не затираются. При отказе import валидатора интерфейс остаётся inert с file_unreadable; автоматический retry/recovery ещё не реализован. У контроллера формы отказ import также оставляет форму inert; retry пока нет.

Настройки сначала записывают candidate, затем заменяют live settings и применяются. При отказе URL остаётся в поле, reset/успех не вызываются; тема/язык возвращают value и не применяются. При успехе theme/lang применяются сразу. D02 о нескольких вкладках этим не решён. D04 не конвертирует значок в PNG: I01 остаётся отдельным.

До записи D06/U03: 26/26 VM-сценариев полного нормализатора (22 неверные структуры и четыре группы сохранения/defaults/extra fields); 21/21 сценарий выделенных load/save/writable/commitData, обработчиков и startup с mock storage/DOM/FKE/FK/render и управляемым Promise вместо import. Подробности прежней передачи находятся в версии этого документа на 9c07dd1. Эти проверки не были выполнением полной оболочки.
