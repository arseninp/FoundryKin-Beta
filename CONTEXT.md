## Проект
FoundryKin — мобильное веб-приложение для редактирования текстур Minecraft Bedrock и сборки `.mcpack`. Владелец работает с Android-телефона. Приложение открывается как `app.html` (адрес на GitHub Pages: `https://arseninp.github.io/FoundryKin-Beta/app.html`, со слов владельца; я его не открывал). Репозиторий `arseninp/FoundryKin-Beta`, ветка `main`. Резервные ветки: `backup-0.8.21-2026-10-11` (на коммите `617c749`, до удаления 2D), старые `backup` и `backup-0.8.0`.

Рабочая цепочка: владелец формулирует задачи, DeepSeek пишет подробные ТЗ текстом (у него безлимитный поиск по файлам), ты читаешь ТЗ, сверяешь с кодом, пишешь код и записываешь в GitHub через `github_mcp_direct`.

## Словарь
- **Finder / FINDER** — экран поиска блоков (вкладка Add texture). Русский вариант «Поисковик» заложен в `fk-app.js`, язык пока не переключается.
- **Карточка** — одна кнопка `.fkc` из двух пузырей: `.fkp` (превью) и `.fkn` (название). У изменённого блока класс `fk-edited` и красная рамка.
- **3D-снимок карточки** — статичный PNG, отрендеренный один раз в WebGL; не путать с живым 3D-редактором.
- **Живой 3D-редактор** — вращаемая модель блока в редакторе (`#stage`).
- **Плоскость рисования** — холст `#ed`, на котором рисуют пиксели. Это не 2D-режим.
- **2D-режим / 2D-вид (удалён)** — старый плоский рендер модели `#fb` и кнопка «Переключить 2D / 3D».
- **Пак** — набор изменённых текстур, экспортируется в `.mcpack`. Хранится в `localStorage`.
- **Объект** — блок целиком: несколько файлов текстур (например дверь: верх, низ, иконка).
- **Пузырь версии** — компактная плашка с версией пака и счётчиком под названием пака в шапке.
- **Патчи** — замены строк в тексте `index.html` на лету при его загрузке.

## Файлы и роли
- `app.html` — оболочка и подключение скриптов. Версии скриптов задаются через `?v=` в нём.
- `fk-app.js` — экраны, навигация, паки, хранение, импорт и экспорт `.mcpack`, заголовки (FINDER, пузырь версии), диагностика.
- `fk-style.css` — стили приложения (светлая и тёмная тема через `data-theme` у корня).
- `fk-grid.js` — карточки блоков и их 3D-снимки, патчи редактора (`NEWPATCHES`).
- `fk-bg.js` — сплошной фон модели и карточек (`#d9d4cd` светлая, `#3a3935` тёмная), плавающий поиск, удаление 2D-кнопки; синхронизирует тему редактора с темой приложения.
- `fk-editor.js` — загрузка старого редактора в iframe и его патчи (`PATCHES`), интеграционный API `FKE`.
- `index.html` — старый редактор. Временный, будет выброшен.
- `blocks.json` — каталог блоков. Приложение скачивает его в рантайме с серверов Mojang. Вложения `blocks.json`, которые присылал владелец, лежат только в архиве чата, в репозитории их нет.
- `README.md`, `ROADMAP.md`, `TODO.md`, `ARCHITECTURE.md`, `CONTEXT.md` — документы.

## Ключевые технические факты
- Порядок загрузки: `fk-editor.js` → `fk-grid.js` → `fk-bg.js` → `fk-app.js`. Патчи складываются в общий массив `PATCHES` и применяются при открытии редактора. Диагностика в настройках показывает «применено N из M» и список не нашедших место.
- Данные: `localStorage`, ключи `fk070_packs` и `fk070_settings`. Импорт ограничен примерно 2–3 МБ.
- 3D зависит от `three.js` r128 с CDN и от WebGL. Нет 3D — карточки пустые.
- Карточки: ортографическая камера, углы (0.6155, −0.7854), модель центрируется по габариту и только уменьшается, никогда не увеличивается. Крестики растений стоят под 0° и 90° к граням куба.
