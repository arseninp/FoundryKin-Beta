## Продукт и сохранение

Мобильный веб-редактор текстур Minecraft Bedrock и сборщик .mcpack. Владелец проверяет на Android. Рабочий адрес: https://arseninp.github.io/FoundryKin-Beta/app.html.

Путь: Create → создать/импортировать пак → открыть пак → Find → блок → редактирование → Add. Рисование само по себе не сохраняет изменения в пак. PNG скачивается из редактора; .mcpack экспортируется из списка паков. При выходе из редактора есть предупреждение о недобавленных правках, затем поиск восстанавливает данные активного пака. Полный регрессионный тест этого пути ещё требуется.

## Правила работы

- Русский язык, коротко и по делу; один обоснованный путь без постоянного выбора вариантов.
- Каждая запись кода — новая версия. Обновлять FK_V и параметры кэша затронутых подключений. Документация отдельно версию не повышает.
- Не более 25 000 байт UTF-8 на файл. fk-core.js уже 24 990 Б: следующий рост требует осмысленного перераспределения функций, не удаления полезного кода или бессмысленного сжатия.
- Перед записью показать состав, размеры UTF-8 и ожидаемые Git blob SHA; получить подтверждение инструмента с точными полными аргументами. После согласования байты не менять.
- Предпочитать цельный коммит. Если запись разбита, каждый вызов подтверждается отдельно; неполную сборку не объявлять готовой.
- Перед записью сверить HEAD, чтобы не перезаписать параллельный запуск. После записи перечислить корень по SHA нового коммита и сверить файлы.
- Git blob SHA: SHA-1 от b'blob ' + str(len(bytes)).encode() + b'\0' + bytes.
- Перед записью JS — node --check. Для CSS/UI проверять реальные размеры элементов в браузере; это не заменяет Android-тест.
- Временная среда может сбрасываться. Сохранять цельный архив проверенного набора и проверять наличие; никогда не угадывать потерянные байты.
- Не утверждать «работает на телефоне» по синтаксису, заглушкам или совпадению SHA. Отдельно писать, что запускалось, а что не проверено.
- Никаких PATCHES, текстовых замен HTML, перевода готового DOM поверх русской базы, наблюдателей для исправления чужой разметки и повторных обработчиков вместо замены исходных.
- Общие шрифт, палитры и шапка — fk-base.css. Новые разделы используют общие компоненты; не копировать размеры в отдельные страницы.
- Документы обновлять по просьбе владельца. Не переносить незаписанные возможности в «готово».

## Подписи слотов: важно

slotLabels получает текущий список слотов, убирает путь/расширение, общий начальный префикс по словам, заменяет _ пробелами. Нет ограниченного словаря top/side/carried: front on, overlay, inside, upper, lower и прочие части сохраняются. Если обрезание оставило бы пустую строку, остаётся полное очищенное имя. Полный путь показывается в title кнопки.

При нескольких ключах назначения сохраняется составная подпись (например top + bottom). Группировка по одному пути текстуры не меняется, отдельные дубли холстов для одной текстуры не создаются. Построение подписи не находится в цикле рендера. Проверить подписи на реальных блоках; одноимённые файлы из разных папок пока могут иметь одинаковые короткие подписи.

## Хранилище и ограничения

fk070_packs = {active,packs}; fk070_settings — тема, адрес редактора, язык. Пак: id/name/author/desc/version/game/icon/textures; текстура: path без textures/ и расширения, data URL, иногда obj/all. Импортированные UUID: keep/mod.

fk_hist — история до 20 цветов; fk_brush — размер кисти. Миграция fk_hist_v2 удалена. Кэши: foundrykin.catalog.v3, foundrykin.exist.v2.

localStorage ограничивает размер; импорт ориентировочно 2–3 МБ, зависит от квоты. Очистка данных браузера удаляет паки. Интернет/CDN и WebGL нужны; PWA/гарантированного офлайна нет. Не советовать очищать данные ради обновления интерфейса.
