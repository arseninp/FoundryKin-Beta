## Проект

Мобильное веб-приложение для редактирования текстур блоков Minecraft Bedrock и сборки `.mcpack`. Владелец работает с Android-телефона. Единственный поддерживаемый запуск: https://arseninp.github.io/FoundryKin-Beta/app.html. Это оболочка; `index.html` — внутренний старый редактор, не основной адрес приложения.

Пользователь создаёт пак, открывает Find, выбирает блок, редактирует его текстуры и нажимает «Добавить». Пак экспортируется из списка паков. Рисование само по себе не добавляет правки в пак. При выходе с недобавленными правками показывается подтверждение; возврат к поиску восстанавливает сохранённые текстуры активного пака.

## Как работать с владельцем

- Русский язык, коротко и по делу. Не перегружать вариантами, предлагать один обоснованный путь.
- Каждое изменение кода приложения — новая версия. Обновлять FK_V и `?v=` изменённых ресурсов. Правки только документации не повышают версию приложения.
- Перед внешней записью показать полный состав, размеры UTF-8 и ожидаемые Git blob SHA. Использовать подтверждение инструмента с точными аргументами и полным содержимым; не заменять его общим согласием. После согласования не менять состав и байты.
- Предпочитать один полный коммит версии. Не записывать половину согласованного набора. Если запись разделена, каждый отдельный вызов требует своего подтверждения; неполную версию нельзя объявлять готовой.
- После записи перечислить корень репозитория через `get_file_contents(path='/', sha=новый_коммит, fields=['name','sha','size'])` и сверить таблицу. Параметр fields фильтрует список каталога, не содержимое отдельного файла.
- Git blob SHA: SHA-1 от `b'blob ' + str(len(utf8_bytes)).encode() + b'\0' + utf8_bytes`.
- Файлы записываются целиком. Перед JS-записью `node --check`; для патчей проверять якоря и синтаксис итогового редактора.
- Не говорить «работает на телефоне» по одному синтаксическому тесту. Отдельно описывать реальные тесты и заглушки. Локальный Chromium доступен через Playwright; синхронные тесты удобно запускать отдельным Python-процессом. Настоящий Android, CDN, шрифты и 3D требуют отдельной проверки.
- Локальные рабочие файлы могут исчезнуть между обращениями. Исходная истина — GitHub, а не временная папка или старое вложение. Для большой работы сохранять единый промежуточный архив и повторно проверять его наличие.
- GitHub-коннектор иногда возвращает только SHA или обрезанный текст. Проверять полноту; не угадывать отсутствующие байты. При необходимости запросить ZIP репозитория, сверить его файлы с GitHub.
- Перед рискованной переделкой создать резервную ветку и проверить её SHA. Обычная частота — раз в 4–5 версий и по просьбе владельца.
- Не менять интерфейс вне согласованного ТЗ. Макеты задают цвета; старые сетки инструментов и радужные полосы на макетах не являются требованиями к новым функциям.
- Не плодить новые надстройки. Новый функционал встраивать в исходные места; заменённые обработчики и мёртвые ветки удалять. Один отдельный модуль локализации допустим, DOM-перевод поверх старых строк — нет.
- Документы обновлять по просьбе владельца; сейчас они приведены к 0.8.33. Не добавлять описание незаписанных возможностей в «Сделано».

## Файлы и роли

- `app.html` — оболочка, экраны, поля, подключение CSS/JS, FK_V; Google Fonts Montserrat 400/500/800.
- `fk-style.css` — базовые стили оболочки. Актуальные цвета и шапки поверх них задаёт `fk-ui.js`.
- `fk-app.js` — навигация, список/форма паков, черновики до Save, localStorage, импорт/экспорт, добавление текстур, сообщения, диагностика. Создаёт исходный заголовок редактора, который затем оформляет `fk-shell.js`.
- `fk-editor.js` — PATCHES, загрузка и преобразование index.html в iframe.srcdoc, API FKE, режимы search/edit, учёт изменений и диагностика патчей. Функция tidy переносит служебные элементы в справку.
- `fk-grid.js` — NEWPATCHES для каталога, моделей и связи с активным паком; сетка Find, ленивые 3D-снимки, загрузка PNG/TGA, подстановка сохранённых текстур, возврат прокрутки. Дополняет и оборачивает FKE.
- `fk-bg.js` — патчи фона, синхронизация темы iframe с оболочкой и удаление прежнего переключения вида из интерфейса. Его базовые цвета переопределяются fk-ui.js.
- `fk-help.js` — патчи сокращения текстов, справка по ⋮ в поиске и редакторе, полное имя файла, ошибки и ручная загрузка каталога. Использует менеджер FKM из редактора; перехватывает кнопку назад оболочки, чтобы сначала закрыть меню.
- `fk-tools.js` — патчи рисования и интерфейса редактора. Кисть 1–8, альфа, палитра HSV/RGBA/Hex и история, повороты/отражения, капля замены точного цвета, меню настроек 16/32/64, единые SVG, FKM для закрытия меню. Внедряет функции в index.html через извлечение тела функции `inj`. Отключает каркас подменой THREE.LineSegments; это технический долг, не окончательное решение рендера.
- `fk-shell.js` — оформление Find с бесцветной SVG-лупой на кнопке и в заголовке, однострочный заголовок редактора «название блока + пузырь файла», обрезка длинных имён. Использует MutationObserver на #title, созданном fk-app.js. Не хранит паки, не рисует 3D и не переводит интерфейс.
- `fk-ui.js` — цвета обеих тем из макетов, отклик на нажатия без синего tap-highlight Chrome, плавающие пузыри шапок, перенос назад в Find, скрытие лишней полосы. Пузырь файла остаётся внутри названия. Поднимает шапку с 24 до 8 px при прокрутке; резервирует место под началом контента. Дополнительно оформляет шапку пака в одну строку. Главная шапка пока не превращена в пузырь.
- `index.html` — старый исходник редактора. Реальная программа в iframe получается после применения патчей; чтение одного index.html не показывает все функции 0.8.33.
- `blocks.json`, `terrain_texture.json` — внешние данные Mojang, загружаются в рантайме; не собственные исходники проекта.

## Текущее поведение

- Find: сетка в три колонки, статичные ортографические 3D-превью, названия до двух строк, красная рамка изменённых блоков. Поиск по английским идентификаторам Mojang. Шапка: [назад] [поле Find с лупой] [⋮].
- Редактор: вращаемая модель, выбор формы/текстуры, холст. Отмена/повтор и четыре преобразования стоят над холстом; отдельная пипетка слева от кисти/ластика/заливки/капли. Капля меняет все пиксели точно того же RGBA на текущей текстуре, не соседние оттенки. Счётчика замен нет.
- Палитра: без предустановленных образцов; выбранные цвета добавляются в начало истории до 20 элементов. Удержание образца открывает удаление. Нижнее меню: квадрат HSV, круглые индикаторы, оттенок, альфа, RGBA, Hex. Применение по галочке; отмена по фону/назад.
- Нижний ряд: «Заменить», «Скачать» (PNG), «Очистить», настройки, ⋮. Имя блока и экспорт mcpack убраны из видимого редактора, но скрытые узлы и код в старой базе ещё есть.
- Настройки редактора: кисть 1–8 для кисти и ластика, разрешение 16/32/64. Смена разрешения масштабирует текстуры и сбрасывает историю; размер кисти сохраняется.
- FKM закрывает меню палитры, настроек и справки по повторному нажатию, фону и history.back. Кнопка назад приложения сначала закрывает меню. Android-жест отдельно проверять на устройстве.
- Create: две широкие кнопки «Создать пак»/«Добавить Mcpack». Новый пак создаётся только по «Сохранить»; пустое имя становится my_pack. Изменения имени, автора, описания, версий и иконки — черновик до Save. Предпросмотр manifest создаётся при открытии существующего пака и после Save, не при наборе текста.
- Шрифт: Montserrat 800 для заголовков/кнопок, 500 для тела, 400 для мелкого. JSON и отчёт диагностики остаются моноширинными.
- Цвета: светлая bg #e6e3dc, panel #d5d0ca, line #b2ada7, accent #718198; тёмная bg #262625, panel #383733, line #51504e, accent #6d7791. Рамка правок #a4757b/#a47c7c. Это приближение по JPEG-макетам.
- Синие основные действия: «Добавить», «Сохранить», «Создать пак». Нижний Find сейчас нейтральный: выделение голубым входит в следующую задачу.
- Локализация не сделана. Интерфейс смешивает русский и английский. Есть проверки состояния по русскому тексту и подмены исходных строк.

## Хранение и ограничения

Паки: `fk070_packs` = `{active,packs}`; настройки: `fk070_settings`. Пак содержит id, name, author, desc, version, game, icon, textures; текстура — path без префикса textures/ и расширения, data URL, иногда obj и all для группировки. Импортный pack может иметь keep/mod для UUID. Иконка пака и слот иконки двери — разные сущности.

История цветов: `fk_hist`; миграция удаления старых стандартных образцов: `fk_hist_v2`; кисть: `fk_brush`. Кэш внешних каталогов: `foundrykin.catalog.v3`, `foundrykin.exist.v2`. Старое отдельное сохранение редактора отключено патчами; основное хранилище паков находится в fk-app.js.

Импорт примерно до 2–3 МБ: проверки объёма base64 и всего JSON, плюс фактическая квота localStorage. Очищение данных браузера удаляет паки. Требуются интернет для CDN/каталога и WebGL для превью; офлайн/PWA ещё нет. Модели части блоков приблизительные. Поддержка 64px добавлена в рисование; повторное открытие/импорт/экспорт 64px нужно проверить целиком, старый FKE.editTexture распознаёт только 16/32.
