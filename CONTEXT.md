## Задача владельца

Каталог — пользовательские объекты, не список файлов/внутренних ID игры. Одна карточка для выключенного/включённого объекта со всеми уникальными PNG. Дубль, форма, состояние, стадия, кадр анимации — разные отношения. Одинаковый PNG не доказывает одинаковую геометрию.

- Объединять furnace/lit_furnace и аналогичные группы системно; lit/powered — кандидаты, не разрешение на слепое слияние. У lit-печей передняя грань в данных может быть east вместо south.
- Сохранять все пути И исходные позиции массивов с повторами. Пример nether_wart: 4 позиции, 3 PNG. unique paths и variants теперь разделены.
- Azalea: горшечные ресурсы уже есть в blocks.json (down/south/west); старый список слотов их теряет. Нужна форма «В горшке», в том числе цветущая азалия. Предыдущее объяснение про сироты было неверным.
- Bamboo: одна карточка «Росток / Бамбук» и иконка; сохранить принятую составную взрослую модель. Это новое решение заменяет прежнее «бамбук не трогать». Bamboo block и ограды — не стадии растения.
- Аметист: одна стадия по центру вместо четырёх кристаллов вместе.
- Метка icon/иконка по явной роли; окно Shared textures/Общие текстуры на той же странице; высота подписи 1/2/3+ строки; отдельный плеер кадров для блоков и предметов. Всё это в новом интерфейсе пока не сделано.
- Поиск/фильтры: одна каноническая группа; старые имена/ID сохранять. Рекомендация — результат предмета ведёт в связанную группу сразу к иконке. Детальный UX ещё не принят и код поиска не реализован; не выдавать рекомендацию за готовое решение.
