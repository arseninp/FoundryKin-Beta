## Бэкапы: текущее поведение

Один слот на пак. В карточке сверху имя/дата бэкапа; ряды: большая акцентная Текстуры → Создать бэкап либо Восстановить бэкап/Удалить бэкап по половине ширины, тон3 → прежние действия. Замена убрана: удалить и создать заново. Создание — отдельный экран, жирное имя пака, Название бэкапа (необязательно), fallback дата-время, постоянное предупреждение в красной рамке. Успех возвращает в список паков, ошибка оставляет форму/имя.

fk-backup-store.mjs — формат/слот; fk-backups.mjs — экран/карточки/проверка изображений; fk-backup-host.mjs — адаптер к data.backupEntries внутри существующей записи fk070_packs, не отдельные фактические localStorage-ключи и не IndexedDB. Создание только по действию пользователя. Восстановление — весь сохранённый пак, не палитры/прочие паки; снимок остаётся. Удаление пака удаляет его бэкап одной записью после предупреждения. Общая очистка паков тоже удаляет бэкапы после предупреждения. Установку кода не путать с выполнением этих действий над данными владельца.
