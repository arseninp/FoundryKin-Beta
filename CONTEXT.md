## Окончательные решения OLDCHAT30

Для bubble_column/end_portal/end_gateway сохраняем общий sprite/WebGL-путь и квадратные карточки. Режим «без рендера», пустой builder и новый renderer НЕ выбраны: более ранние предложения архива отменены позднейшим решением. Нужна будущая честная пометка: игровой эффект создаёт Minecraft; здесь показана исходная текстура, доступная для редактирования и экспорта. Это не готовая симуляция.

Общие текстуры: будущая плашка относится к выбранному файлу, не ко всем ресурсам объекта сразу. Показывать связанные видимые карточки/формы/состояния без дублей, учитывать borrowed dependencies; использовать существующий индекс, не вторую таблицу. Текущий compiledInfo.shared по всем файлам не выдавать за точные последствия правки одного файла.

Будущий фильтр «Иконки»: та же карточка с адресным входом на ресурс; объекты без иконок исключаются из этой выдачи. Не второй каталог. Это согласованное направление обсуждения, не реализованный фильтр.

Начальный разворот голов исправлять согласованно в карточках и редакторе, без зеркалирования/перестановки UV. 180° — кандидат для подтверждённых голов, не глобальная поправка всему каталогу. Швы/пропадающие поверхности — отдельная диагностика. Масштаб свечей/грибов/ростков пока не менять; решение должно быть единым. Версия следующего согласованного обновления — 1.0.0; в этом docs-only пакете runtime-версия не меняется.

## Рабочие правила

Кратко и понятно по-русски. Исправлять причину в соответствующем слое, без второго каталога/menu/runtime, fallback на первую PNG и повторной реализации готовой геометрии. Сохранять source IDs, aliases, owned/carried/icons/indexed repeats/shared dependencies, PNG/form/slot/state/pose независимо.

В main разрешены необходимые изменения и удаления после проверки зависимостей, но каждую внешнюю запись подтверждать точным пакетом; после проверять saved diff/content. После записи продолжать подготовку той же задачи без ожидания «продолжай», до следующего подтверждения/решения/блокера. Новые постоянные тестовые файлы отдельно согласовывать; существующие проверки не ослаблять. Каждый файл <25000 UTF-8 bytes.
