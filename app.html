Паки и текстурыPacks and textures

На главном экране откройте список паков, создайте пак или импортируйте .mcpack. Кнопка «Текстуры» открывает содержимое пака, а поиск — каталог для выбора объекта.From the home screen, open the pack list and create a pack or import a .mcpack. The Textures button opens the pack contents; Find opens the catalog to select an object.

Сохранение и экспортSaving and export

Сохранение в редакторе добавляет изменённые текстуры в активный пак. Экспорт пака создаёт файл .mcpack. Выгрузка данных в разделе «Память» — отдельный JSON-файл, а не .mcpack.Saving in the editor adds edited textures to the active pack. Exporting a pack creates a .mcpack file. The data export under Storage is a separate JSON file, not a .mcpack.

Сравнение и бэкапыComparison and backups

«До» показывает текстуры на момент входа в карточку, включая уже сохранённые изменения пака. Это не отмена правок. Внутренний бэкап создаётся в карточке пака; восстановление заменяет сохранённый пак, а сам бэкап остаётся.Before shows textures as they were when you opened the card, including existing pack edits. It is not Undo. Create an internal backup on a pack card; restoring it replaces the saved pack and keeps the backup.
