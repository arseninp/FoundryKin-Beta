# FoundryKin: план развития

## Сделано (v0.3.3)
- 3D-просмотр куба, плиты, ступеней; запасной 2D-вид
- Каталог блоков из bedrock-samples, семьи по общему файлу текстуры
- Оригинальная текстура как основа, правка, отмена/повтор, заливка, пипетка
- Экспорт PNG и .mcpack, автосохранение в браузере

## Ближайшее (приоритет)
1. Меню по данным игры: переключатель «верх/бок/низ» только у блоков с разными гранями; у блоков с одной текстурой он скрыт.
2. Шесть граней для блоков с передом (печь, бочка, улей, тыква).
3. Панель семьи: список блоков с общей текстурой и превью их форм (плита, ступени, забор, стена, калитка, кнопка).
4. Актуальность данных: привязка к релизу bedrock-samples, кнопка «обновить каталог», отметка новых блоков.

## Дальше
5. Импорт своего пака (.zip/.mcpack) прямо в браузере: твои текстуры становятся основой вместо оригинала.
6. Хранилище IndexedDB вместо localStorage, экспорт и импорт проекта файлом.
7. Работа офлайн: библиотеки лежат в репозитории, PWA для установки на экран.
8. Экспорт: свои название, иконка, постоянные UUID для обновления пака, проверка манифеста.
9. Vibrant Visuals / PBR: texture_set.json, слои MER, нормали и карта высот.
10. Анимированные текстуры (кадры), тонированные блоки (трава, листва).
11. Инструменты: симметрия, сдвиг, поворот, проверка бесшовности, палитра из текстуры.
12. Предметы, мобы, интерфейс (вне блоков).

## Риски и вопросы
- Правила использования оригинальных текстур Mojang и названия: проверить перед публикацией.
- Версия игры 26.3 против нумерации 1.26.50.x в документации: сверить формат.
- Сбои доставки сообщений в чате: не выходить из приложения во время ответа.
