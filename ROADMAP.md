## Известные проблемы

- localStorage: квота, импорт примерно 2–3 МБ, потеря локальных паков при очистке браузера; требуется IndexedDB.
- Сеть/CDN нужны для первого запуска; автономная установка не реализована, каталог может грузиться медленно.
- WebGL обязателен для 3D; сбой оставляет пустые превью.
- Часть форм приблизительна; старый путь editTexture распознаёт размер только 16/32, цикл 64px нужно проверять.
- Язык смешанный, нет единого i18n; поведение местами зависит от русского текста.
- Архитектура состоит из патчей, обёрток и распределённых CSS. Нельзя назвать текущий код чистым только по внешнему виду.
- Последняя версия пузырей требует проверки поведения на разных экранах/телефонах и при открытом меню/клавиатуре.
- Юридические вопросы по ресурсам и модель монетизации не решены.

Резервные ветки: создавать перед рискованными правками и раз в 4–5 версий. Последняя — backup-0.8.33-2026-10-14 на aa0f357.
