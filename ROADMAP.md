# FoundryKin — ROADMAP

Текущая версия: 0.8.5. Последний бэкап: ветка `backup-0.8.0` (на момент записи — v0.8.1).

## Правила работы

- Бэкап делаем раз в 4–5 версий, без напоминаний: при готовой версии предлагаю запрос на обновление ветки.
- Версия `fk-app.js`, `fk-editor.js` и `fk-grid.js` берётся из `?v=` в `app.html`.
- Каждую запись проверяем по SHA файлов и по диагностике в настройках.
- Новые надстройки поверх старого кода не плодим: всё временное вычищаем при переписывании перед пререлизом.

## Единый поиск (в переписанном каталоге)

Поиск без разделов: блоки, предметы, частицы и сущности в одном списке. Объект целиком (блок, составные текстуры, иконка) открывается одной страницей, в паке показывается одной карточкой.

- [ ] Каталог предметов игры: путь иконки брать из него, а не угадывать по имени (дверь, кровать, табличка, подвесная табличка, котёл, варочная стойка, цветочный горшок, воронка, повторитель, компаратор, костёр — список ориентировочный, проверить по каталогу).
- [ ] Частицы: плоский вид.
- [ ] Сущности: сначала плоский вид, объёмное превью позже.
- [ ] Метка типа объекта в данных пака нужна для правильных путей (ui, entity, blocks, items).
