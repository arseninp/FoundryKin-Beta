# FoundryKin — ROADMAP

Стратегия на одну страницу. Ближайшие задачи по порядку — в `TODO.md`. Текущая версия: 0.8.22.

## Сделано
- Поиск сеткой с лениво подгружаемыми карточками: превью (3D-снимок) и подпись в двух пузырях, красная рамка у изменённых блоков.
- Пак группирует файлы по объектам; импорт и экспорт `.mcpack` (до 2–3 МБ).
- Текстуры активного пака подставляются в поиск и редактор поверх ванильных.
- Изометрия карточек, центрирование моделей, растения под 45°, сплошной фон по макетам, плавающий поиск.
- 2D-вид модели убран из интерфейса.

## Платформы и права
- Решение по платформе: веб с установкой (PWA) и IndexedDB; десктопная и мобильная оболочки после переписывания.
- Юридический вопрос: использование ванильных текстур Mojang в публичном и платном приложении. Возможно, убрать упоминание названия игры и загружать ванильный пак у самого пользователя.

## Известные проблемы
- Текстуры иногда грузятся медленно из каталога Mojang: нужны кэш и показ прогресса.
- Паки больше 3 МБ не импортируются (ограничение хранилища браузера).
- Часть форм блоков отображается неточно.
- 3D требует WebGL и `three.js` с CDN.

## Правила
- Бэкап-ветка раз в 4–5 версий. Последняя: `backup-0.8.21-2026-10-11`.
- Новые надстройки поверх старого кода не плодим: временное только через патчи и вычищается при переписывании.
- Каждую запись проверяем по размеру и Git blob SHA.
