# ROADMAP — FoundryKin

Обновлено 2026-10-25. Задачи по пунктам: TODO.md. Правила и решения: CONTEXT.md.

## Видение

Один лёгкий и быстрый мобильный редактор текстур Bedrock для блоков, предметов, сущностей, UI и colormap, без фризов, на чистой кодовой базе, затем коммерческий выпуск.

## Фазы

1. Единый просмотр (шаги A, B, C из TODO.md P0): геометрия не зависит от экрана, общие текстуры и материалы, один рендерер, отрисовка по запросу, ручной поворот.
2. Регрессия и измерения на Android: полный цикл Add → PNG → .mcpack, плавность Find, память.
3. Закрытие блоков: оставшиеся специальные формы и состояния (TODO.md P2).
4. Бетонирование: реестр моделей, один модуль помощников, удаление всего устаревшего кода, возможно переписывание под новый формат. Проект не должен держаться на костылях и обёртках. Делать после того, как визуальные правки закончатся; бэкап перед стартом.
5. Сущности: универсальный рендер .geo.json (кости, кубы, UV), реальные атласы, камера класса 4 для крупных мобов; различающихся моделей немного, доделывается быстро. Неквадратные текстуры в ядре — предпосылка.
6. Предметы: каталог, поиск, иконки (плоский неподвижный режим уже есть для textures/items/).
7. UI и colormap: плоское точное редактирование без 3D.
8. Подготовка к выпуску: IndexedDB и большие паки, резервирование пользовательских данных, PWA и офлайн-политика, обновление каталога под новые версии игры, права на ресурсы Mojang.
9. Монетизация: решение о модели откладывается до состояния «почти готово». Открытые вопросы: что именно продаётся, какие ресурсы Mojang допустимо распространять, платформа публикации. Отложенные идеи: subpacks, тон ±5%, платформенные оболочки.

## Критерий готовности модели

Реальный WebGL-кадр совпадает в Find и редакторе; нет обрезки и потери частей; проверка владельца на Android; Add → reopen → PNG → .mcpack без повреждения. Зелёный тест на заглушке этого не заменяет.
